# Gamla Skolan – Palworld-panel

Startas med genvägen "Palworld Panel" (skrivbord/Start-menyn). Styr servern i
`C:\Program Files (x86)\Steam\steamapps\common\PalServer` via Palworlds REST API, som panelen
slår på automatiskt (med ett slumpat adminlösenord) i PalWorldSettings.ini.

Inställningar för panelen: `panel-data/panel-settings.json`. Lyssnar bara på 127.0.0.1:8029.
